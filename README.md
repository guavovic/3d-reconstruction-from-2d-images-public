# 3D Reconstruction from 2D Images

Tool that generates 3D models from 2D images using a custom artificial intelligence.

## About

Source code developed for my final paper. The project explores computer vision and machine
learning techniques to reconstruct three-dimensional models from a set of two-dimensional images.

## Tech Stack

Python, computer vision libraries and a custom AI model.

## Academic Context

Final paper — Information Systems, UNIFEBE.
